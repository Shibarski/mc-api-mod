SOOP 인증 및 방송 연동 절차

Minecraft Fabric 1.21.11 · 싱글플레이용 시청자 참여형 모드

게임 GUI·시뮬레이터 구현OAuth 기초 코드 작성 · 미검증실시간 SOOP 연동 개발 예정

이 문서는 SOOP 계정 본인 인증부터 방송국 정보 확인, 방송 연결, 연동 해제 및 정보 처리 방식까지를 설명하는 개발·심사 안내 자료입니다. 실제 서비스 연결 성공을 증명하는 자료가 아닙니다.

현재 개발 상태 · SOOP 앱 등록/Consent 권한 승인 전이므로 실제 계정 인증, 방송국 API 응답, 방송 상태 조회와 채팅·후원·구독 수신은 검증하지 못했습니다. 아래 단계별 상태를 반드시 구분해 확인해 주세요.

1. 인증 및 연동 처리 흐름

  1. 1
    게임 내 [SOOP 로그인] 선택 GUI 구현

    스트리머가 싱글플레이 월드에서 단축키로 설정 GUI를 열고 로그인 버튼을 선택합니다. 승인 전에는 인증 정보가 없어 브라우저 인증을 완료할 수 없습니다.

  2. 2
    브라우저에서 OAuth 인증 및 권한 동의 기초 코드 작성 · 미검증

    모드는 등록된 애플리케이션의 Client ID를 이용해 SOOP 인증 페이지를 요청합니다. 스트리머가 SOOP에서 로그인하고, 허용할 권한을 직접 확인·동의하는 구조입니다.

  3. 3
    로컬 콜백으로 인증 코드 수신 기초 코드 작성 · 미검증

    인증 결과를 http://127.0.0.1:8081/soop/callback에서 받도록 설계했습니다. OAuth 요청의 무작위 state 값을 비교해 요청 위조를 방지하고, 인증 코드는 일회성으로 처리합니다. 해당 콜백 주소는 실제 앱 등록 값과 일치해야 합니다.

  4. 4
    HTTPS 토큰 교환과 방송국 정보 조회 기초 코드 작성 · 미검증

    SOOP 인증 서버에 코드를 전달해 접근 토큰을 받도록 작성했습니다. 그다음 승인된 방송국 정보 API에서 방송국 이름과 닉네임을 읽어 연결 화면에 표시하도록 계획했습니다.

  5. 5
    본인 방송 상태 확인·이벤트 수신 개발 예정

    방송 여부 확인 API로 본인의 방송 시작·종료를 확인하고, 승인된 권한 범위에서 채팅·별풍선·구독 이벤트를 수신해 미리 설정한 게임 명령어를 실행할 예정입니다. 현재는 SOOP 데이터 대신 가상 이벤트 시뮬레이터를 사용합니다.

  6. 6
    연동 해제 및 정보 정리 로컬 기초 코드 작성

    [연동 해제] 시 로컬 인증 토큰과 계정 표시 정보의 메모리 참조를 제거하는 코드를 작성했습니다. 실제 방송 수신 중단 동작은 승인 후 연결하여 검증할 예정입니다. 이 기능은 SOOP 서버 측 권한 철회와 다릅니다.

2. 방송국 정보 조회의 목적과 데이터

현재 계획한 방송국 정보 사용 목적은 연결한 계정 확인과 방송국 이름 표시입니다. 방송 중 여부는 방송국 이름으로 판단하지 않고 별도의 방송 상태 확인 기능으로 확인할 예정입니다.

응답 필드의미모드 이용 계획
station_name방송국 이름연결 화면 표시
user_nick스트리머 닉네임방송국 이름이 없을 때 보조 표시
profile_image프로필 이미지 경로표시·저장하지 않을 계획
lately_broad_date최근 방송 날짜사용하지 않을 계획
favorite_cnt애청자 수사용하지 않을 계획
위 필드 이름은 공개 연동 구현을 참고한 예상 응답 항목입니다. 아직 MC API MOD의 승인된 앱으로 실제 SOOP 응답을 확인하지 못했습니다. 승인 후 공식 문서·실제 응답과 비교하여 수정하겠습니다.

3. 정보 저장·삭제 및 로그 처리

OAuth 인증 정보

초기 버전은 인증 코드·토큰·방송국 표시 정보를 사용 중 메모리에서 처리하도록 설계했습니다. 토큰은 JSON 파일에 저장하지 않으며, 게임 종료·로컬 연동 해제 때 참조를 폐기합니다. 실제 토큰 교환은 미검증입니다.

이벤트 설정

사용자가 지정한 채팅 키워드·명령어·확률 등의 규칙은 config/mc_api_mod.json에 저장됩니다. 설정 초기화 또는 파일 직접 삭제로 정리할 수 있습니다.

채팅·후원 화면 표시

실시간 데이터 저장소는 별도로 운영하지 않을 계획입니다. 다만 게임 채팅창에 표시한 시청자 닉네임과 메시지 등은 마인크래프트 자체 로그에 남을 수 있습니다.

기본 게임 로그 삭제

게임 종료 후 해당 인스턴스의 logs/ 폴더에 있는 latest.log와 날짜별 압축 로그를 확인할 수 있습니다. 자동 삭제 기간은 보장하지 않으며 사용자가 직접 삭제해야 합니다.

로그 접근 권한·보관 조건과 상세 삭제 방법은 개인정보 처리방침 5장 및 7장을 참조하세요.

4. 현재 확인 가능한 구현 자료

다음은 현재 구현된 화면·기능입니다. 실제 SOOP 인증 성공 및 API 연결의 증빙과 구분됩니다.

  • 설정 GUI: 연결·채팅·후원·구독·정보 탭, 싱글플레이 단축키
  • 이벤트 관리: 규칙 추가·수정·삭제, 개별 ON/OFF, 발동 확률
  • 시뮬레이터: 가상 채팅, 별풍선 후원, 신규/갱신 구독을 게임 명령어로 테스트
  • 알림 표시: 가상 후원자의 닉네임과 별풍선 개수를 게임 채팅창에 출력
  • 인증 코드: 로컬 콜백과 토큰 교환 등 기초 구현은 있으나 실제 SOOP 인증이 검증되지 않음
SOOP 재심사 증빙으로 별도 첨부할 파일: 실제 GUI 스크린샷, 이벤트 시뮬레이터 실행 영상, 게임 로그 테스트 결과, 배포된 테스트용 JAR 주소. 승인 전 단계의 인증 화면은 실제 연결 성공 화면으로 소개하지 않습니다.
