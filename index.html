SOOP 방송 참여를
마인크래프트 속 이벤트로.

MC API MOD는 Minecraft Fabric 싱글플레이에서 채팅 명령어, 별풍선 후원, 구독에 반응하는 게임 이벤트를 제공하기 위한 개인 개발 프로젝트입니다. 현재는 이벤트 설정·시뮬레이터를 구현했으며, 실제 SOOP 데이터 수신은 아직 제공하지 않습니다.

테스트 방법 보기현재 구현 현황개인정보 처리방침

이 프로젝트는 독립적으로 개발 중이며 SOOP의 공식 서비스나 제휴 제품이 아닙니다.

개발 예정 · 미제공

테스트 방법과 시연

실제 SOOP 계정을 연결하지 않고도 게임 내 이벤트 실행 과정을 확인할 수 있습니다.

게임 내 테스트 절차

  1. Fabric 1.21.11 환경에서 모드를 실행합니다.
  2. 치트가 허용된 싱글플레이 월드를 엽니다.
  3. 키보드 ; 키로 설정 GUI를 엽니다.
  4. 채팅 탭 → 채팅 명령어 관리에서 !좀비 이벤트를 등록합니다.
  5. 연결 탭 → 이벤트 시뮬레이터에서 !좀비를 입력합니다.
  6. 등록한 명령어가 게임 내에서 실행되는지 확인합니다.

이벤트 처리 예시

가상 채팅: !좀비
↓ 저장된 규칙 검색
↓ 활성화·확률 판정
/summon minecraft:zombie ~ ~ ~
※ 실제 SOOP 채팅 화면이 아닌 동작 예시

후원과 구독 이벤트도 별도 시뮬레이터 버튼으로 테스트할 수 있습니다.

배포·시연 자료 준비 중
정식 공개 전 실제 실행 스크린샷, 시연 영상, 테스트용 JAR의 다운로드 경로를 추가할 예정입니다. 현재 이 페이지에는 확인되지 않은 다운로드 링크를 표시하지 않습니다.

정보 및 데이터 삭제 안내

게임 내 정보 → 설정 초기화를 선택하거나, 게임의 config/mc_api_mod.json 파일을 삭제해 로컬 이벤트 설정을 제거할 수 있습니다.

OAuth 연동 해제는 메모리의 인증 정보를 삭제하며, SOOP 서버의 권한 철회와는 구분됩니다. 자세한 내용은 개인정보 처리방침을 확인해 주세요.
