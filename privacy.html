서비스 개발 및 API 승인 안내

MC API MOD는 현재 개발 중이며, SOOP API의 실제 계정 인증 및 실시간 방송 연동은 아직 완료되지 않았습니다.

아래에서 개발 예정으로 표시된 기능은 SOOP API의 지원 범위와 권한 승인 여부를 확인한 후 구현 및 검증할 예정입니다.

1. 개인정보 처리 목적

MC API MOD는 Minecraft Fabric 싱글플레이 환경에서 SOOP 방송 시청자가 게임 진행에 참여할 수 있도록 개발 중인 모드입니다.

SOOP API 승인 후 다음 목적에 필요한 최소한의 정보를 처리할 예정입니다.

  1. 스트리머 본인의 SOOP 계정 인증 및 연결 확인
  2. 방송국 정보 조회를 통한 연결 계정 확인
  3. 방송 진행 여부 확인 및 연결 상태 관리
  4. 실시간 채팅 표시 및 명령어 인식
  5. 별풍선 후원 및 구독 이벤트 처리
  6. 마인크래프트 게임 이벤트 실행

2. 처리하는 개인정보 항목

2.1. 스트리머 계정 정보

OAuth 인증과 방송국 정보 조회를 통해 다음 정보를 처리할 예정입니다.

  • SOOP 계정 및 방송국 식별에 필요한 정보
  • 방송국 이름(station_name)
  • 스트리머 닉네임(user_nick)
  • OAuth 인증 코드
  • OAuth 접근 토큰 및 갱신 토큰
SOOP 계정의 비밀번호는 MC API MOD에서 수집하거나 저장하지 않습니다.

2.2. 방송 채팅 및 이벤트 정보

공식 API에서 제공되고 사용 권한이 승인된 범위에서 다음 정보를 처리할 예정입니다.

  • 방송 채팅 메시지 내용
  • 발신자 닉네임 및 필요한 식별정보
  • 별풍선 후원자 닉네임과 후원 개수
  • 신규 구독 및 구독 갱신 이벤트 정보

해당 정보는 스트리머의 게임 화면에 표시하거나 등록된 이벤트를 실행하는 용도로 사용할 예정입니다.

2.3. 게임 설정 정보

  • 채팅 명령어 및 이벤트 설정
  • 이벤트 발동 확률 및 활성화 여부
  • 후원·구독 이벤트 실행 조건

게임 설정은 이용자의 PC에 있는 로컬 JSON 파일에 저장됩니다.

3. 방송국 정보 조회 및 이용 방법

SOOP OAuth 인증 완료 후 방송국 정보 조회 API를 통해 인증된 방송국의 정보를 확인할 예정입니다.

3.1. API 응답 항목 및 사용 목적

다음은 공개된 SOOP 연동 구현에서 확인한 응답 필드를 기준으로 정리한 항목입니다. MC API MOD에서 실제로 사용할 항목과 사용하지 않을 항목을 구분했습니다.

응답 필드 정보 사용 여부
station_name 방송국 이름 연결 화면 표시
user_nick 스트리머 닉네임 보조 표시 정보
profile_image 프로필 이미지 경로 사용하지 않을 예정
lately_broad_date 최근 방송 날짜 사용하지 않을 예정
favorite_cnt 애청자 수 사용하지 않을 예정

위 필드 목록은 실제 승인된 애플리케이션에서 검증한 응답이 아닙니다. API 승인 후 실제 응답 항목을 확인하고 필요한 경우 본 처리방침을 수정할 예정입니다.

3.2. 조회 정보의 실제 사용 목적

  1. [연결] 설정 화면에 인증된 방송국의 이름을 표시합니다.
  2. 스트리머가 본인의 SOOP 계정으로 연결했는지 확인합니다.
  3. 본인 방송 연결 대상 및 상태 관리에 필요한 정보를 확인합니다.

방송국 이름이 제공되지 않는 경우 스트리머 닉네임을 보조 표시 정보로 사용할 예정입니다.

방송 진행 여부는 별도의 방송 상태 확인 API를 통해 판단하며, 방송국 정보 조회 결과만으로 방송 여부를 판단하지 않습니다.

기능에 사용하지 않는 응답 정보는 별도로 저장하지 않도록 개발할 예정입니다.

4. 로그인 및 정보 전달 절차

SOOP API 승인 이후 다음 순서로 계정 연결 기능을 제공할 예정입니다.

  1. 스트리머가 게임 내 [SOOP 로그인] 버튼을 선택합니다.
  2. 기본 브라우저에서 SOOP OAuth 로그인 및 권한 동의를 진행합니다.
  3. 인증 완료 후 이용자 PC의 로컬 콜백 주소(127.0.0.1)로 인증 코드를 전달받습니다.
  4. 인증 요청의 state 값을 검증합니다.
  5. HTTPS 통신을 통해 SOOP 인증 서버에서 접근 토큰을 발급받습니다.
  6. 방송국 정보를 조회하여 연결된 계정을 확인하고 설정 화면에 표시합니다.
  7. 방송 진행 여부를 확인하고 승인된 권한 범위에서 실시간 채팅 및 이벤트 수신을 시작합니다.
  8. 방송 종료 또는 연동 해제 시 수신과 이벤트 실행을 중단합니다.
현재 구현 상태

OAuth 및 로컬 콜백 기초 코드는 작성되어 있으나 실제 SOOP 계정 인증과 API 연결은 검증되지 않았습니다.

5. 개인정보 보관 기간 및 방법

5.1. OAuth 인증 정보

초기 버전은 인증 정보를 프로그램 실행 중 메모리에서만 처리하도록 설계했습니다.

정보 보관 방법 및 기간
OAuth 인증 코드 토큰 발급 시 일시적으로 사용하며 별도 파일에 저장하지 않을 예정
접근 토큰 인증이 필요한 동안 메모리에 보관
갱신 토큰 필요한 경우 실행 중 메모리에 보관
방송국 표시 정보 계정 연결 상태가 유지되는 동안 메모리에서 사용

게임 종료 또는 연동 해제 시 인증 정보의 메모리 참조를 제거하도록 구현할 예정입니다.

초기 버전에서는 인증 토큰을 로컬 설정 파일이나 별도의 외부 데이터베이스에 저장하지 않을 계획입니다.

5.2. 채팅 및 이벤트 정보

실시간 채팅, 후원 및 구독 정보는 이벤트 처리와 화면 표시를 위해 일시적으로 사용하며, 모드 자체의 별도 채팅 기록 데이터베이스는 운영하지 않을 예정입니다.

다만 마인크래프트 기본 채팅창에 표시된 메시지는 마인크래프트의 게임 로그에 기록될 수 있습니다.

5.3. 게임 로그에 남을 수 있는 개인정보

게임 로그에는 실제 출력 방식과 게임 및 런처 설정에 따라 다음 정보가 기록될 수 있습니다.

  • 시청자 닉네임
  • 방송 채팅 메시지
  • 후원자 닉네임 및 별풍선 개수
  • 구독 이벤트 관련 출력 메시지

5.4. 게임 로그 저장 위치

게임 로그는 마인크래프트 실행 디렉터리의 다음 폴더에 저장될 수 있습니다.

logs/

대표적인 로그 파일은 다음과 같습니다.

  • latest.log — 최근 게임 실행 기록
  • 날짜-번호.log.gz — 이전 게임 실행 기록

기본 마인크래프트 런처에서는 일반적으로 다음 경로를 사용합니다.

%appdata%\.minecraft\logs

Prism Launcher 등 인스턴스별 게임 폴더를 사용하는 런처에서는 저장 위치가 다를 수 있습니다.

5.5. 로그 접근 권한

로그 파일은 스트리머가 게임을 실행하는 로컬 PC에 저장됩니다.

해당 PC의 사용자 계정, 시스템 관리자 및 이용자가 접근 권한을 부여한 프로그램이 파일에 접근할 수 있습니다.

MC API MOD 운영자는 해당 로그를 별도로 수집하거나 이용자 PC에 원격으로 접속하여 열람하지 않습니다.

5.6. 로그 보관 기간

게임 로그의 보관 기간은 마인크래프트 및 사용하는 런처 환경에 따라 달라질 수 있습니다.

MC API MOD는 기본 게임 로그에 별도의 자동 삭제 기간을 설정하지 않습니다.

로그는 게임 또는 런처에 의해 교체·정리되거나, 이용자가 직접 삭제할 때까지 남을 수 있습니다.

5.7. 로그 삭제 방법

  1. 마인크래프트 게임을 종료합니다.
  2. 해당 게임의 실행 디렉터리를 엽니다.
  3. logs 폴더로 이동합니다.
  4. 개인정보가 포함된 로그 파일을 확인합니다.
  5. 필요한 경우 해당 로그 파일을 삭제합니다.
주의

로그 파일을 삭제하면 게임 오류 분석에 필요한 기록도 함께 사라질 수 있습니다.

MC API MOD의 [연동 해제] 기능만으로 이미 생성된 게임 로그는 자동 삭제되지 않습니다.

별도의 채팅 기록 모드, 방송 프로그램, 화면 녹화 프로그램 및 백업 시스템이 생성한 기록은 해당 프로그램의 관리 방법에 따라 별도로 삭제해야 합니다.

5.8. 게임 설정 보관

이벤트 설정은 이용자 PC의 다음 파일에 저장됩니다.

config/mc_api_mod.json

설정 파일은 이용자가 설정을 초기화하거나 직접 삭제할 때까지 보관될 수 있습니다.

6. 접근 권한 및 보안 조치

MC API MOD는 다음 보안 원칙을 적용하도록 개발할 예정입니다.

  1. 스트리머 본인이 동의한 SOOP API 권한만 사용합니다.
  2. OAuth 인증 시 무작위 state 값을 생성하고 검증합니다.
  3. SOOP 인증 서버와 HTTPS로 통신합니다.
  4. 인증 토큰을 일반 GUI나 로그에 노출하지 않습니다.
  5. 계정 정보는 필요한 기능 수행에만 사용합니다.
  6. 승인되지 않은 API 권한으로 정보를 요청하지 않습니다.
  7. 공개 배포용 모드에 Client Secret이 노출되지 않도록 안전한 인증 구조를 적용할 예정입니다.

별도의 계정 정보 저장 서버나 데이터베이스는 초기 버전에서 운영하지 않을 계획입니다.

SOOP 공식 인증 및 API 연결을 위해 필요한 정보는 해당 서비스 서버로 전달될 수 있으며, 이용자 개인정보를 별도의 광고·분석 목적으로 제공하지 않을 예정입니다.

7. 연동 해제 및 개인정보 삭제

7.1. 모드 내 연동 해제

다음 경로에서 SOOP 연동을 해제할 수 있도록 구현할 예정입니다.

MC API MOD 설정 → 연결 → 연동 해제

연동 해제 시 다음 작업을 수행하도록 구현할 예정입니다.

  1. 실시간 정보 수신 중단
  2. 추가 API 요청 및 이벤트 실행 중단
  3. 인증 토큰의 메모리 참조 제거
  4. 계정 및 방송국 표시 정보 제거
  5. 연결 상태를 미연결로 변경

현재 로컬 인증 정보 제거를 위한 기초 코드는 작성됐으나, 실제 SOOP API 연결 상태에서 전체 절차가 검증된 것은 아닙니다.

7.2. SOOP 권한 철회

모드 내부의 [연동 해제]는 로컬 인증 정보를 폐기하는 기능이며, SOOP 서버 측에 발급된 인증 권한을 자동으로 철회한다는 의미는 아닙니다.

이용자는 SOOP에서 제공하는 연결 서비스 관리 기능을 통해 별도로 애플리케이션의 접근 권한을 철회할 수 있습니다.

권한이 철회되거나 인증이 유효하지 않은 경우 API 요청을 중단하도록 개발할 예정입니다.

7.3. 로컬 설정 삭제

게임 내 [설정 초기화] 기능을 이용하거나 다음 파일을 직접 삭제할 수 있습니다.

config/mc_api_mod.json

설정 초기화는 이벤트 설정을 초기값으로 되돌리는 기능으로, 로그 파일까지 삭제하는 기능은 아닙니다.

7.4. 게임 로그 삭제

이미 생성된 게임 로그는 자동 삭제되지 않으므로, 이용자가 게임 종료 후 logs 폴더에서 확인하고 직접 삭제할 수 있습니다.

7.5. 서비스 이용 종료 및 계정 탈퇴

MC API MOD는 별도의 회원가입 기능이나 자체 회원 데이터베이스를 운영하지 않을 예정입니다.

이용을 종료하려는 경우 모드 연동을 해제하고, SOOP 측 권한을 철회한 뒤, 필요에 따라 로컬 설정 및 로그 파일을 삭제할 수 있습니다.

SOOP 계정 자체의 탈퇴 및 SOOP 서버에 저장된 정보 삭제는 SOOP에서 제공하는 절차에 따라 진행해야 합니다.
