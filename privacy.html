개발 중 문서
현재 SOOP 실시간 API 연동은 미제공입니다. 이 문서는 현재 구현 방식과 향후 연동 시 적용할 처리 원칙을 구분합니다. 심사 제출 전에 실제 이메일·시행일을 입력하고, 프로그램의 동작과 일치하는지 확인해야 합니다.

1. 서비스와 운영자

MC API MOD는 마인크래프트 Fabric 싱글플레이용 시청자 참여형 모드를 개발 중인 개인 프로젝트입니다.

2. 현재 처리하는 정보

현재 제공되는 로컬 설정과 시뮬레이터 기능은 SOOP 계정 인증이나 실제 채팅 수신 없이 작동합니다. 사용자가 등록한 채팅 키워드, 별풍선 개수 조건, 구독 이벤트 종류, 실행 명령어, 발동 확률 및 ON/OFF 설정은 사용자 컴퓨터의 JSON 설정 파일에 저장될 수 있습니다.

위 설정은 사용자가 입력한 문자열에 개인정보를 직접 포함하지 않는 한 일반적인 게임 설정 정보이며, 별도의 개발자 운영 서버로 업로드하지 않도록 설계되었습니다.

3. SOOP 연동이 제공되는 경우의 처리 예정 항목

향후 SOOP API 이용 권한을 승인받고 기능을 제공할 경우, 사용자가 동의한 권한 내에서 계정·방송국 식별정보, 방송 상태, OAuth 인증 토큰 및 방송 채팅 또는 후원·구독 이벤트 중 해당 기능에 필요한 데이터만 처리할 계획입니다. 현재 이러한 실시간 수신 기능은 제공되지 않습니다.

실제 제공 전에 권한, 처리 항목, 목적과 이용 범위를 검증하고 이 방침을 갱신하겠습니다.

4. 보관 위치와 기간

  • 이벤트 설정: 사용자 컴퓨터의 config/mc_api_mod.json에 저장되고, 사용자가 직접 삭제하거나 초기화할 때까지 남습니다.
  • 인증 토큰(향후 OAuth 이용 시): 현재 개발용 코드에서는 실행 중 메모리 보관을 기본으로 하며, 별도의 지속 저장은 계획하지 않습니다. 게임 종료 또는 로컬 연동 해제 시 메모리 참조를 폐기하도록 설계되어 있습니다.
  • 실시간 채팅(향후 제공 시): 메시지 판단과 게임 내 표시 목적의 일시적 처리만 계획하며, 개발자 운영 서버에 별도 보관하지 않도록 설계할 예정입니다.

5. 정보 이용과 제3자 제공

게임 이벤트 실행과 설정 관리 외의 목적으로 정보를 사용하지 않을 계획입니다. 현재 자체 운영 서버로 개인정보를 전송하거나 제3자에게 판매·제공하는 기능은 구현하지 않았습니다. 향후 외부 서비스에 필요한 API 통신이 발생하면 그 대상과 목적을 공개하겠습니다.

6. 접근·보안 조치

모드 설정은 기본적으로 사용자의 로컬 환경에서 관리합니다. 계정 로그인 비밀번호는 수집하지 않으며, OAuth 토큰을 일반 화면이나 로그에 기록하지 않도록 설계합니다. 인증 보안 관련 기능은 공개 배포 전 별도 검증할 예정입니다.

7. 연동 해제 및 삭제 방법

  • 게임에서 MC API MOD 설정 → 정보 → 설정 초기화를 선택하면 이벤트 설정이 초기화됩니다.
  • 게임 종료 후 마인크래프트 게임 폴더의 config/mc_api_mod.json을 삭제하면 로컬에 저장된 이벤트 설정을 직접 제거할 수 있습니다.
  • 향후 SOOP 로그인 기능이 실제 활성화되면 모드의 연동 해제 기능으로 로컬 인증 토큰 참조를 폐기할 계획입니다. 이는 SOOP 서버에서의 권한 철회와 별도이므로, SOOP 계정의 연결 서비스 관리에서 동의를 철회해야 할 수 있습니다.
  • 로컬 데이터 삭제나 개인정보 문의는 위에 기재된 운영자 이메일로 요청할 수 있도록 운영할 예정입니다. 개발자가 보유하지 않는 사용자의 로컬 파일은 개발자가 원격으로 삭제할 수 없습니다.

8. 처리방침 변경

새로운 SOOP API 연동 기능과 데이터 처리 방식이 추가되면 변경 내역과 시행일을 이 페이지에 공개합니다. 본 문서가 실제 구현·운영 상태와 다를 경우 공개 및 심사 제출 이전에 수정합니다.
