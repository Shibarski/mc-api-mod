01

1. 개인정보 처리 목적

MC API MOD는 SOOP 방송과 마인크래프트를 연동하여 시청자 참여형 게임 이벤트를 제공하기 위해 개발 중인 프로그램입니다.

SOOP API 승인 후 다음 목적에 필요한 최소한의 정보를 처리할 예정입니다.

  1. 스트리머 본인의 SOOP 계정 인증 및 연결 확인
  2. 방송국 정보 조회를 통한 연결 계정 확인
  3. 방송 진행 여부 확인 및 실시간 연결 상태 관리
  4. 실시간 채팅 메시지 표시 및 명령어 인식
  5. 별풍선 후원 및 구독 이벤트 처리
  6. 스트리머가 지정한 마인크래프트 게임 이벤트 실행
02

2. 처리하는 개인정보 항목

2.1. 스트리머 계정 정보

SOOP OAuth 인증 및 방송국 정보 조회를 통해 다음 정보를 처리할 예정입니다.

  • SOOP 계정 및 방송국 식별에 필요한 정보
  • 방송국 이름(station_name)
  • 스트리머 닉네임(user_nick)
  • OAuth 인증 코드
  • OAuth 접근 토큰 및 갱신 토큰

SOOP 계정 비밀번호는 수집하거나 저장하지 않습니다.

2.2. 방송 채팅 및 이벤트 정보

공식 API에서 제공되고 사용 권한이 승인된 범위에서 다음 정보를 처리할 예정입니다.

  • 방송 채팅 메시지 내용
  • 메시지 발신자의 닉네임 및 필요한 식별정보
  • 별풍선 후원자의 닉네임과 후원 개수
  • 신규 구독 및 구독 갱신 이벤트 정보

해당 정보는 스트리머의 게임 화면 표시 및 등록된 이벤트 실행에 사용합니다.

2.3. 게임 설정 정보

  • 채팅 명령어 및 게임 이벤트 설정
  • 이벤트 실행 확률 및 활성화 여부
  • 후원·구독 이벤트 실행 조건

게임 설정은 이용자의 PC에 있는 로컬 JSON 파일에 저장합니다.

03

3. 방송국 정보 조회 및 이용 방법

SOOP OAuth 인증 완료 후 방송국 정보 조회 API를 통해 인증된 계정의 방송국 이름과 스트리머 닉네임을 확인할 예정입니다.

조회한 정보는 다음 용도로 사용합니다.

  1. 마인크래프트 모드의 [연결] 화면에 현재 연결된 방송국 표시
  2. 스트리머가 본인의 SOOP 계정으로 인증했는지 확인
  3. 본인 방송의 연결 대상과 상태를 관리하기 위한 정보 확인

방송 진행 여부는 별도의 방송 여부 확인 기능을 통해 판단하며, 방송국 이름과 닉네임만으로 방송 중인지 판단하지 않습니다.

방송국 정보 조회 응답에 포함된 기타 정보는 해당 기능에 필요하지 않다면 별도로 저장하지 않도록 개발할 예정입니다.

04

4. 로그인 및 정보 전달 절차

SOOP 계정 연결은 다음 절차로 구현할 예정입니다.

  1. 스트리머가 게임 내 [SOOP 로그인] 버튼을 선택합니다.
  2. 기본 브라우저에서 SOOP OAuth 로그인 및 권한 동의를 진행합니다.
  3. 인증 완료 후 이용자 PC의 로컬 콜백 주소(127.0.0.1)로 인증 코드를 전달받습니다.
  4. 인증 요청 시 생성한 state 값을 검증하여 인증 요청의 유효성을 확인합니다.
  5. HTTPS 통신을 통해 SOOP 인증 서버에서 접근 토큰을 발급받습니다.
  6. 승인된 API로 방송국 정보를 조회하고 연결 계정을 확인합니다.
  7. 인증이 완료되면 모드 설정 화면에 연결 상태와 방송국 정보를 표시합니다.

SOOP 계정 인증 및 API 요청은 SOOP에서 제공하는 공식 인증 체계와 승인된 권한 범위 내에서 진행할 예정입니다.

05

5. 개인정보 보관 기간 및 방법

5.1. OAuth 인증 정보

초기 버전에서는 인증 토큰을 프로그램 실행 중 메모리에만 보관하도록 설계했습니다.

  • 인증 코드: 토큰 발급 과정에서 일시적으로 사용
  • 접근 토큰: API 인증이 필요한 동안 메모리에 보관
  • 갱신 토큰: 필요한 경우 프로그램 실행 중 메모리에 보관
  • 계정 및 방송국 표시 정보: 연결 상태를 표시하는 동안 메모리에서 사용

게임 종료 또는 연동 해제 시 해당 정보의 메모리 참조를 제거하도록 구현할 예정입니다.

인증 토큰을 별도의 로컬 설정 파일이나 외부 데이터베이스에 저장하지 않는 것을 초기 버전의 원칙으로 합니다.

5.2. 채팅 및 이벤트 정보

실시간 채팅, 후원 및 구독 정보는 이벤트 처리를 위해 일시적으로 사용하며, 별도의 채팅 기록 데이터베이스를 운영하지 않을 예정입니다.

이용자의 게임 화면에 출력된 메시지는 마인크래프트 자체의 기록 또는 로그 설정에 따라 별도로 남을 수 있습니다.

5.3. 게임 설정

이벤트 설정은 이용자의 PC에 있는 다음 경로에 저장됩니다.

config/mc_api_mod.json

해당 설정은 이용자가 설정 초기화 기능을 사용하거나 파일을 직접 삭제할 때까지 유지될 수 있습니다.

06

6. 접근 권한 및 보안 조치

MC API MOD는 다음 보안 원칙을 적용하도록 개발할 예정입니다.

  1. 스트리머 본인이 동의한 SOOP API 권한만 사용합니다.
  2. OAuth 인증 과정에서 무작위 state 값을 생성하고 검증합니다.
  3. SOOP 인증 서버와의 통신에는 HTTPS를 사용합니다.
  4. 인증 토큰을 일반 GUI나 로그에 노출하지 않습니다.
  5. 계정 정보는 필요한 기능 수행에 한정하여 사용합니다.
  6. 승인되지 않은 API 권한으로 정보를 요청하지 않습니다.
  7. 배포용 모드에 Client Secret이 노출되지 않도록 안전한 인증 구조를 적용합니다.

서비스 운영을 위한 별도의 계정 정보 저장 서버나 데이터베이스는 초기 버전에서 운영하지 않을 계획입니다.

07

7. 연동 해제 및 개인정보 삭제

7.1. 모드 내 연동 해제

이용자는 게임 내 다음 경로를 통해 SOOP 연동을 해제할 수 있도록 개발할 예정입니다.

MC API MOD 설정 → 연결 → 연동 해제

연동 해제 시 다음 작업을 수행하도록 구현할 예정입니다.

  1. SOOP 실시간 정보 수신 중단
  2. 추가 API 요청 및 이벤트 실행 중단
  3. 메모리에 보관된 인증 토큰 참조 제거
  4. 계정 및 방송국 표시 정보 제거
  5. 연결 상태를 미연결로 변경

모드 내부의 연동 해제는 로컬 인증 정보를 폐기하는 것으로, SOOP 서버 측에서 발급한 권한 자체를 철회하는 것과는 구분됩니다.

7.2. SOOP 계정 권한 철회

이용자는 SOOP에서 제공하는 연결 서비스 관리 기능을 통해 별도로 애플리케이션 접근 권한을 철회할 수 있습니다.

권한이 철회되거나 계정 인증이 유효하지 않은 경우 추가 API 요청을 중단하도록 구현할 예정입니다.

7.3. 로컬 설정 삭제

이용자는 게임 내 설정 초기화 기능을 사용하여 저장된 이벤트 설정을 초기화할 수 있습니다.

완전한 로컬 설정 삭제를 원하는 경우 마인크래프트 설정 폴더의 config/mc_api_mod.json 파일을 직접 삭제할 수 있습니다.

MC API MOD는 별도의 회원가입 및 자체 회원 계정 시스템을 운영하지 않을 예정입니다.

이용자 PC에 저장된 로컬 데이터는 운영자가 직접 원격 삭제할 수 없으므로, 연동 해제 및 로컬 설정 삭제 절차를 안내합니다.

SOOP 서버에 보관되는 정보 및 SOOP 계정 자체의 삭제는 SOOP에서 제공하는 절차에 따라 진행해야 합니다.

9. 개발 및 서비스 운영 상태

현재 구현된 기능은 다음과 같습니다.

  • 마인크래프트 모드 설정 GUI
  • 채팅·후원·구독 이벤트 설정 및 관리
  • 이벤트별 실행 확률 설정
  • 가상 채팅·후원·구독 이벤트 시뮬레이터
  • 로컬 JSON 설정 저장
  • OAuth 로그인 및 로컬 연동 해제 기초 코드

OAuth 인증의 실제 계정 연결과 SOOP 실시간 API 수신은 아직 검증 및 구현이 완료되지 않았습니다.

SOOP API 승인 후 인증, 방송 상태 조회, 실시간 채팅·후원·구독 연동 기능을 개발하고 관련 보안 및 삭제 절차를 검증한 뒤 제공할 예정입니다.

본 개인정보 처리방침은 실제 서비스 구현 및 운영 내용에 맞추어 수정될 수 있으며, 변경 사항은 서비스 안내 페이지를 통해 공지하겠습니다.
